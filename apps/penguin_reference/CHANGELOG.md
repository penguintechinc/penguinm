# Changelog

All notable changes to Penguin Reference will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-14

### Added

- Initial release of Penguin Reference
- Home feature module with greeting list
- Feature flag gating for all features
- Offline support with connectivity monitoring
- OTel telemetry emission (logs, metrics, traces)
- Support for dev, beta, and prod flavors
- Integration with penguinm backend
